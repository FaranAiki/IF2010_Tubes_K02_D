Ini tugas besar bom bom

Untuk *package*, digunakan nabla yang merupakan singkatan dari Nangor Blast (nabla lebih keren dan singkat).

Berikut adalah penjelasan hierarki pada git ini
 config/                untuk konfigurasi
 doc/                   untuk dokumentasi dan milestone
 src/                   kode sumber nangor blast
    exception/         (jika dibutuhkan)
    game/               workflow dari game
    util/               kelas pembantu/helper
    input/              input untuk player (WASD, arrows, .etc)
    model/              entitas seperti Player, BasicEnemy, Map, dan sebagainya
    gui/                model implementasi dari semua di atas pada bentuk guinya
